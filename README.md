# Calculator in React

## Overview
This project is a simple calculator built with React, designed for learning purposes. The goal is to create a straightforward interface that allows for basic arithmetic operations such as addition, subtraction, multiplication, and division.

## How to Use
- **Components**: The calculator will consist of buttons and an input field for entering numbers and operations.
- **Functionalities**: When clicking the buttons, values will be added to the input, and calculations will be performed upon pressing the equals button.
- **Purpose**: This project is ideal for anyone learning React and wanting to practice building interactive interfaces.

## Structure
- **App Component**: The main component that manages the calculator interface.
- **Buttons and Input**: Interactive elements for entering data and performing operations.

# Calculadora em React
## Visão Geral
Este projeto consiste em uma calculadora desenvolvida em React, voltada para aprendizado. O objetivo é criar uma interface simples que permita realizar cálculos básicos como adição, subtração, multiplicação e divisão.

## Como Usar
- **Componentes**: A calculadora será composta por botões e um campo de entrada (input) para inserir números e operações.
- **Funcionalidades**: Ao clicar nos botões, os valores serão adicionados ao input, e o cálculo será realizado ao pressionar o botão de igual.
- **Objetivo**: Este projeto é ideal para quem está aprendendo React e quer praticar a criação de interfaces interativas.

## Estrutura
- **App Component**: Componente principal que gerencia a interface da calculadora.
- **Botões e Input**: Elementos interativos para inserir dados e realizar operações.
